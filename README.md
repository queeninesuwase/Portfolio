# Olive Noir Portfolio

A responsive personal developer portfolio using Next.js, TypeScript, React, and CSS.

## Run locally

1. Install Node.js 20.9 or newer.
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Visit http://localhost:3000.

## Customize before publishing

- Replace the placeholder LinkedIn URL in `app/page.tsx` with your actual profile link, or switch it to your preferred contact method.
- Review your name, location, skills, descriptions, and project links.
- Add your own headshot, résumé, and project screenshots if you want them.
- Confirm public sharing permissions and safety of any linked collaborative code repositories.

## Project files

- `app/page.tsx`: page content and project list
- `app/globals.css`: colors, typography, layout, mobile responsiveness
- `app/layout.tsx`: metadata and root document
- `package.json`: scripts and dependencies

No paid APIs, database, or authentication are required for this portfolio site.
